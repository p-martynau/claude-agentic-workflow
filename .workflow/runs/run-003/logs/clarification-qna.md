# Clarification Q&A — run-003

Asked by `requirements-formalizer` before `requirements.md` was written. The residents'
association (synthetic requester) answered all questions in the same session.

1. **Q:** Which Bristol area/park do you prefer, or should we propose options?
   **A:** No fixed park — please propose options, ideally reachable by bus with some on-site or
   nearby parking, since street parking is limited.

2. **Q:** Is Saturday 6 June 2027 fixed, or is there flexibility if the weather looks bad?
   **A:** The date is fixed (coordinated with other residents' association plans). We need a solid
   rain contingency rather than a new date.

3. **Q:** What atmosphere/style are you going for (formal, casual, themed)?
   **A:** Casual, inclusive, family-friendly community-fete style. No formal dress code or theme.

4. **Q:** Any allergies beyond needing a vegetarian and a halal-friendly option?
   **A:** No specific allergies flagged yet, but please ask caterers to label common allergens
   (nuts, gluten, dairy) on any buffet.

5. **Q:** Preferred output format and language?
   **A:** English. A readable Markdown plan plus a simple printable/standalone web page version.

6. **Q:** Any must-have elements or firm exclusions?
   **A:** Must include something for young children (under 6) and something accessible for older
   adults with limited mobility. No fairground rides (cost and safety) and no alcohol sales.

7. **Q:** Does the 13:00–18:00 window include setup/cleanup, or is that guest-facing time only?
   **A:** 13:00–18:00 is guest-facing time. Setup can start earlier and cleanup can run later,
   within whatever the chosen venue allows.

8. **Q:** Any preferred source types for research (e.g. only council-run venues, only certain
   caterers)?
   **A:** No preference — real, currently operating Bristol venues/vendors are fine as long as
   they are verifiable.

All eight questions were answered in this session, so no items remain open pending user input.
