# Services Plan — 8th Birthday Party (run-001)

## Status
READY

## Purpose
Plan the vendor/service categories the confirmed requirements actually need beyond venue,
activities, and catering: decoration, and small party-run extras. No music/DJ, photography,
security, or transport was requested and none of these is required by the event's scale or
formality, so they are not planned (per the agent's instruction not to invent unneeded services).

## Inputs used
- `artifacts/requirements.md` (no specific services/vendors named beyond "kid-friendly activities"
  and basic implied party decoration; informal/casual style; no AV/tech requirement stated)

## Content

### Decoration (sourced, external)
- **What:** A number-8 balloon bouquet (matching the birthday age) plus a small latex balloon
  bunch for the table/entrance, delivered and set up before guest arrival.
- **Estimated cost:** "Double Number Balloon Bouquet" from £70 + "Latex Balloon Bunches" from £20
  = **£90 estimated** (both listed as "From" prices, so the final quote could be somewhat higher
  depending on exact colours/sizes chosen).
- **Setup/teardown time:** Not stated precisely on the source page; budgeted as part of the venue's
  1-hour setup window (11:00–12:00) in `schedule.md`, consistent with typical balloon-delivery
  setup times for a room this size.
- **Constraint fit:** Matches the informal, non-themed style from requirements; affordable within
  the overall budget; no venue-specific installation (e.g., ceiling rigging) required.
- **Source:** [London Party Decor — Setup Prices](https://londonpartydecor.co.uk/setup-prices/)
  (retrieved 2026-09-28), West-London-based balloon decorator serving London-wide events, listing
  "Double Number Balloon Bouquet: From £70" and "Latex Balloon Bunches: From £20."
- **Note:** A separate, larger balloon-decor company (Boutique Party Hire) was also reviewed but
  requires a **£500 minimum spend per booking** — more than 40% of the entire event budget for
  decoration alone — so it was **not selected**.
  Source (for the rejected option, cited for transparency): [Boutique Party Hire — Children's Party Decorations](https://www.boutiquepartyhire.co.uk/product-category/children-party-hire/decorations/).

### Party extras (small, generic, folded in — no separate vendor needed)
- **What:** Pass-the-parcel wrapping/small prizes (~£10) and craft-table supplies for the free-play
  period (~£10–£15), per `activities.md`.
- **Estimated cost:** £20 (midpoint of the ranges above), bought as ordinary party-shop/stationery
  items rather than through a vendor — no external source required for these commodity items.

  in `schedule.md`. This is the services-planner's own stated assumption, not merely an open
  question, and it should still be confirmed with the chosen decorator before booking.
